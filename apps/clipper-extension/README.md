# Glimpse Web Clipper (브라우저 확장)

현재 웹페이지를 Glimpse 데스크톱 보관함으로 저장하는 최소 클리퍼다.
모든 전송은 **같은 기기의 로컬 데스크톱 앱(동기화 서버의 `/v1/clipper`)으로만**
일어난다 — 외부 서버가 없다.

## 설치 (Chrome / Edge, 개발자 로드)

1. Glimpse 데스크톱 앱을 실행한다(로컬 서버가 34129 포트로 함께 뜬다).
2. `chrome://extensions` → 개발자 모드 → **압축해제된 확장을 로드** → 이 디렉터리 선택.
3. 툴바의 Glimpse 아이콘 클릭 → 선택 텍스트(또는 제목+링크)를 저장.

데스크톱 동기화 포트를 바꿨다면 팝업 하단의 포트 입력을 맞춰 둔다(로컬 저장).

## 보안 설계

- 요청은 루프백(127.0.0.1)으로만 나가고, 서버도 루프백 발신만 받는다.
- 커스텀 헤더 `X-Glimpse-Clipper: 1`이 없으면 서버가 거절한다. 커스텀 헤더는
  cross-origin fetch에서 preflight를 유발하고 이 서버는 CORS preflight에
  응답하지 않으므로, 임의 웹페이지의 자바스크립트가 브라우저에 의해 차단된다.
  프리플라이트 없이 갈 수 있는 폼 POST는 헤더 검증에서 거절된다.
- 동기화 서버의 전역 host 검증(DNS 리바인딩 방어)이 함께 적용된다.

## 데이터

저장되는 것: URL, 페이지 제목, 선택한 텍스트(있을 때).
`KnowledgeItem`(note 타입)으로 저장되며, 기존 데스크톱-모바일 동기화와
지식 그래프 자동 분석 파이프라인을 그대로 탄다.
