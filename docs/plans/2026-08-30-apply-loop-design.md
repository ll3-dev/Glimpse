# 활용 루프 설계 — 채팅 RAG · 그래프→행동 · Shortcuts 캡처

- 날짜: 2026-08-30
- 상태: 승인됨 (안 1: 활용 루프 먼저 — C1→C2→C3 직렬)
- 연관 문서: `docs/plans/2026-08-30-graph-capture-infra-design.md`(트랙 A·B와 병행, 코드 겹침 없음)
- 제약: 다른 세션에서 코드 작성 중 — 본 트랙은 트랙 A/B와 파일이 겹치지 않는 영역만 직렬 진행

## 배경

핵심 루프(캡처→AI 정리→복습→양방향 동기화) 완성 + 그래프/캡처/인프라 설계(트랙 A·B) 확정 이후. 남는 천장은 "저장한 지식이 **쓰이는가**"다:

1. 채팅이 지식 라이브러리와 단절 — "지식 저장" 버튼으로 끝나고 저장한 지식이 대화에 다시 쓰이지 않음.
2. 그래프 연결도가 "보는 것"에 머묾 — 복습 우선순위·digest와 무관.
3. 캡처 진입이 앱 실행 또는 고장 난 ShareExtension뿐 — "3초 안에 저장" 경로 부재.

임베딩 인프라(검색 리랭크용 llama.cpp 배치 임베딩)와 AI 프로바이더 라우터가 이미 있어 **새 인프라 0**으로 세 갈래 모두 연결 작업만으로 가치를 만든다.

## 전체 구조

```
C1  채팅 RAG (데스크톱)        — features/ai 신규 파일 중심
C2  그래프→행동 (복습 가중치 + digest 연결 발견)
C3  iOS Shortcuts 캡처        — A1(ShareExtension 수리) 완료를 선행 조건
```

직렬 진행 원칙: C1 → C2 → C3. 각 단계 구현 → 단위 테스트 → 게이트(bun test + lint + typecheck) → 플랫폼 스모크.

---

## C1. 채팅 RAG — 지식 컨텍스트 자동 주입 (데스크톱)

### 흐름

```
사용자 메시지 → 질문+라이브러리 배치 임베딩 → 코사인 상위 K(≤5)·임계값 이상
→ 시스템 프롬프트에 발췌 주입 → 응답과 함께 "참조한 노트 N" 표시
```

### 설계 결정

1. **프로바이더 시스템 무변경** — `router.ts`·프로바이더 4종(local-llm/BYOK/rules/stub) 그대로. 검색+프롬프트 조립은 `features/ai/knowledge-context.ts`(신규 순수 함수)로 분리하고 채팅 호출부 앞단에만 붙임.
2. **검증된 임베딩 경로 재사용** — `useDesktopSemanticRerank`가 쓰는 llama.cpp 배치 임베딩(`runEmbeddingBatch`, `resolveEmbeddingTarget`)을 동일하게 사용. 훅 로직(`@glimpse/hooks`)의 랭킹/캐시/폴백 정책 재활용.
3. **우아한 폴백** — 임베딩 모델 미로드·LLM 미설정 시 조용히 스킵(기존 채팅과 100% 동일). rules/stub 사용자에게 영향 없음.
4. **UX** — 응답 하단 "참조한 노트" 칩, 클릭 시 라이브러리 해당 아이템으로 이동. 설정 토글(기본 on).
5. **데스크톱 먼저** — 모바일 RAG는 임베딩 경로가 미검증이라 이번 사이클 제외.

### 게이트

- 검색 로직 단위 테스트(코사인 순위·임계값·K 컷·폴백)
- 프롬프트 조립 테스트(컨텍스트 유무별 시스템 프롬프트 형태)
- GUI: 지식 저장 → 채팅에서 관련 질문 → "참조한 노트" 표시 확인

### 파일 겹침

없음. 트랙 A(그래프 파이프라인·모바일 라이브러리), 트랙 B(브리지)는 채팅을 건드리지 않음.

## C2. 그래프→행동 확장

### C2-a. 복습 우선순위에 연결도 반영

- due 아이템 정렬 시 `edgeCount`(그래프 엣지)를 보조 정렬 키로 추가.
- 스코어: `priority = basePriority + w * min(edgeCount, cap)` — w·cap은 상수 1곳.
- 폴백: 엣지 없으면 기존 정렬과 100% 동일.
- 게이트: 정렬 함수 단위 테스트(엣지 유무별 순서), 기존 복습 테스트 회귀.

### C2-b. 데스크톱 daily digest에 "연결 발견" 섹션

- digest에 "이 노트와 이 노트가 연결되어 있어요"를 최근 추가 엣지 상위 3개만 노출. **새 LLM 호출 0** — 기존 엣지 데이터 표시만.
- A2(그래프 증분 파이프라인)가 엣지 백로그를 처리할 때 이 섹션이 산출물의 첫 행동 지점이 됨. A2 착수 전에 랜딩해도 빈 섹션으로 안전.
- 게이트: 컴포넌트 단위 테스트, GUI에서 엣지 추가 시 섹션 갱신 확인.

### 명시적 제외

연결도 기반 간격 조정(스케줄러 변경), 모바일 digest 확장 — YAGNI.

## C3. 새 캡처 채널: iOS Shortcuts + App Intent

### 후보 비교 (확정)

| 후보 | 판단 |
|---|---|
| **iOS Shortcuts (App Intent)** — 채택 | 잠금화면/액션버튼/Siri 진입 공짜, 새 배포 축 없음 |
| 위젯 | 텍스트 입력 불가 — 기각 |
| 웹 클립버드 | 브라우저 확장 배포 축 신규 — 기각 |

### 설계

- **App Intent (Swift)**: `CaptureQuickNoteIntent` — 텍스트 파라미터 1개, 백그라운드 실행.
- **수용 경로**: intent → 앱 공유 컨테이너에 JSON append → 앱 기동/포그라운드 시 기존 캡처 파이프라인으로 흡수. ShareExtension과 **같은 수용 경로 재사용** — A1 수리 시 자동 견고.
- **위임 처리**: 앱 꺼짐 상태 저장 후 알림 배지, 켜진 상태면 라이브러리 실시간 반영.
- **범위 외**: 안드로이드 위젯, 이미지/음성 입력 (YAGNI).
- **게이트**: 실기기/시뮬레이터에서 Shortcuts 앱 → intent 실행 → 앱 실행 시 흡수 확인.
- **선행 조건**: A1(ShareExtension 수리) 완료 — 같은 수용 경로 공유 영역의 동시 작업 방지.

## 전체 검증 원칙

- 모든 단계: 구현 → 단위 테스트 → 게이트(bun test + lint + typecheck) → 플랫폼 스모크 순.
- 각 변경은 커밋 단위로 잘라 커밋 전 diff 확인.
- GUI 수동 확인 항목(C1 참조 노트 표시, C2-b 섹션 갱신, C3 intent 흡수)은 체크리스트로 명시.
- 트랙 A/B 세션과의 충돌 방지: 파일 겹침 0 유지, C3는 A1 완료 후 착수.
