# Glimpse MVP v1 Design

Date: 2026-02-14
Status: Approved
Author: loopy

## Overview

MVP v1은 입력 채널 확장, 주간 다이제스트 추천, 사용자 반응 수집을 구현합니다.

## Goals

- 5개 입력 채널 지원 (메모, 링크, 하이라이트, 스크린샷, 공유)
- 주간 다이제스트로 연결 추천 제공
- 사용자 반응(수락/무시/닫기) 수집

## Data Model

### knowledge_items type extension

```typescript
export const knowledgeItemType = ['note', 'link', 'highlight', 'screenshot', 'share'] as const;
```

### New: recommendations table

```typescript
export const recommendations = sqliteTable('recommendations', {
  id: text('id').primaryKey(),
  itemA_id: text('item_a_id').notNull().references(() => knowledgeItems.id),
  itemB_id: text('item_b_id').notNull().references(() => knowledgeItems.id),
  reason: text('reason'),
  status: text('status', {
    enum: ['pending', 'accepted', 'ignored', 'dismissed']
  }).notNull(),
  createdAt: real('created_at').notNull(),
  respondedAt: real('responded_at'),
});
```

**Status values:**
- `pending`: Initial state
- `accepted`: User explicitly accepted
- `ignored`: User explicitly rejected
- `dismissed`: User temporarily hid (may resurface)

## Decisions Log

| Decision | Options | Chosen | Reason |
|----------|---------|--------|--------|
| Implementation grouping | Full/Grouped/Individual | Grouped | Independent testing, clear dependencies |
| Checkpoint method | Commit/Commit+Verify/Review | Commit+Verify | Catch issues early |
| DB schema for new types | Extend enum/Separate tables/JSON | Extend enum | Simple, extensible |
| Channel switcher UI | Segment tabs/Bottom sheet/Dropdown | Segment tabs | Fast switching, always visible |
| Digest placement | New tab/Home/Library subtab | New tab | Core feature, clear entry point |
| Recommendation storage | Memory/Table/Defer | Table | Persistence for feedback tracking |
| Recommendation status | 3-state/4-state/5+ | 4-state | Distinguish ignore vs dismiss |

## Out of Scope

- Real-time recommendations (weekly only)
- Push notifications
- OCR accuracy improvements
- LLM-based ranking
- Vector search
- Animation transitions
- Channel customization
