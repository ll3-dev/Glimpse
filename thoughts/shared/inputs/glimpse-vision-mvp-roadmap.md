# Glimpse 제품 비전 & MVP 로드맵

## 핵심 문제 인식

- 정보 과잉 + AI 생성 콘텐츠 → **신뢰 문제** 심화
- 개인 지식 저장소의 필요성 증가
- 수많은 정보를 **단일 소스**에서 관리할 수 있는 도구가 필요
- 기존 PKM은 사용자가 직접 연결해야 하는 한계가 있음

---

## Glimpse의 비전

> AI가 내 지식을 자동으로 연결하고, 잊혀질 지식을 적절한 타이밍에 다시 꺼내주는 **프라이버시 중심의 차세대 PKM**
> 

### 3가지 핵심 차별점

### 1. Local LLM 기반 — 프라이버시 + 오프라인

- **기본값은 로컬**: 데이터가 디바이스를 떠나지 않음
- **BYOK (Bring Your Own Key)**: 파워 유저가 자기 API 키로 더 강력한 모델 사용 가능
- **Apple Intelligence 연동**: iOS/macOS 네이티브 AI 기능 활용으로 온디바이스 처리 확장
- "내 지식은 내 디바이스에만"이라는 메시지가 핵심

### 2. 자동 연결 추천 — "이 내용과 이 내용을 엮으면 어떨까요?"

- 기존 PKM: 사용자가 직접 링크를 걸어야 함 (가장 큰 허들)
- Glimpse: AI가 **능동적으로 연결을 제안**
- 예시: *"3일 전 저장한 이 아티클과 오늘 메모한 아이디어가 연결될 수 있어요"*

### 3. 학습 곡선 기반 추천 (Spaced Repetition + PKM)

- 에빙하우스 망각 곡선 원리를 PKM에 적용
- 시간이 지나면 잊혀질 지식을 **적절한 타이밍에 다시 꺼내줌**
- 예시: *"이 메모 작성한 지 2주 됐는데, 최근에 저장한 이 링크랑 연결해보면 어때요?"*
- 기존에 이걸 잘 결합한 제품이 거의 없어서 차별점이 될 수 있음

## 타겟 사용자

- 지식을 많이 다루는 **지식 노동자**부터 **일반 사용자**까지

## 콘텐츠 수집 — 5가지 입력 채널

| 수집 방식 | 설명 |
| --- | --- |
| 📎 링크 저장 | 웹 콘텐츠 아카이빙 |
| ✏️ 메모 | 직접 작성 |
| 🖍️ 하이라이트 | 읽는 중 핵심 발췌 |
| 📸 스크린샷 | 시각 정보 캡처 (OCR 연동 시 텍스트화 가능) |
| 📤 공유 | OS 공유 시트로 다른 앱에서 유입 |

## MVP 로드맵

### MVP v0 — 수집 + 기본 연결

- [ ]  링크 저장 + 메모 (가장 기본적인 2개 입력)
- [ ]  Local LLM으로 저장 시 자동 태깅/요약
- [ ]  수동 검색 ("내가 저장한 것 중에 OO 관련 있어?")

### MVP v1 — 추천 시작

- [ ]  하이라이트, 스크린샷, 공유 입력 채널 추가
- [ ]  주 1회 다이제스트로 연결 추천 시작 ("이번 주 저장한 것들 중 연결할 만한 것")
- [ ]  사용자 반응(수락/무시) 데이터 수집

### MVP v2 — 학습 곡선 적용

- [ ]  망각 곡선 기반 "다시 보기" 추천
- [ ]  추천 빈도를 사용자 반응 기반으로 자동 조절
- [ ]  BYOK / Apple Intelligence 옵션 추가

## 열린 질문 (추후 검토)

- [ ]  로컬 LLM 모델 선정 (Llama, Phi, Gemma 등) 및 모바일 리소스 최적화
- [ ]  추천 UX 형태: 다이제스트 vs 실시간 사이드바 vs 푸시 알림?
- [ ]  추천 빈도의 최적 밸런스 (너무 자주 → 노이즈, 너무 적으면 → 존재감 없음)
- [ ]  스크린샷 OCR 처리를 로컬에서 어디까지 할 수 있는지
- [ ]  데이터 동기화: 멀티 디바이스 시 로컬 데이터 싱크 전략
