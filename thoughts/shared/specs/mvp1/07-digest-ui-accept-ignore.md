# MVP v1-07 다이제스트 UI + 수락/무시 SPEC

## 문제
추천을 표시하고 반응을 받는 UI가 없으면 v1 핵심 가치(연결 추천)를 사용자에게 전달할 수 없습니다.

## 해결 목표
**현재:** 연결 후보를 사용자에게 보여줄 화면이 없습니다.
**목표:** 주간 추천 카드 목록을 표시하고 각 항목에 수락/무시 액션을 제공합니다.

## 성공 기준
- [ ] 추천 카드에 연결 대상 2개와 근거가 표시된다.
- [ ] `수락`, `무시` 액션이 각각 동작한다.
- [ ] 액션 직후 UI 상태(버튼 비활성/상태 배지)가 갱신된다.

## 범위 제한
- 추천 상세 설명 생성 제외.
- 카드 드래그 제스처 제외.
- 알림/배지 시스템 연동 제외.
